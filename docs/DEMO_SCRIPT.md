# Three-minute demo script

Start from a reset (header badge → **Reset demo data**), signed in as **Maya Patel, Lead advisor** at Northlight. Client: **Sarah Chen**.

**0:00 · Set the scene (15s).** "Maya advises Sarah. Context about Sarah is scattered across meetings. Recall.IQ turns it into memories that Maya controls, and an agent that acts on them." Point at the badge: say which services are live and which are demo.

**0:15 · Ingest and confirm (40s).** Memory → **1 · May meeting note** → *Extract proposed memories*. Four separate proposals appear: possible family support, why the proposal was declined, the revisit condition, and Maya's commitment. Each one quotes the exact sentence and is labeled *Source-supported · unconfirmed*. Confirm all four.

**0:55 · Fresh run (35s).** Workspace → *Start fresh agent run*. Walk the stages: access → retrieval → freshness → planning → validation → saving. The brief lists two open questions. Three memory-driven draft tasks appear: confirm the renewal, clarify family support, and the deferred revisit **on hold**. Click **Why this?** on the hold task to show the memory versions and the source excerpts. Note that the agent prepares drafts and only Maya can approve.

**1:30 · Correct (35s).** Memory → **2 · November update** → *Extract*. The system proposes **updates** to two confirmed memories (strikethrough old → new) plus one new memory. Nothing is replaced until Maya clicks *Confirm & replace*. Back on Workspace, the drafts that depended on the old versions are marked **Needs review**.

**2:05 · Next run changes behavior (30s).** *Start fresh agent run*. "What changed in this run" shows three tasks **withdrawn** and a new **Prepare the deferred proposal discussion** task, each with "Because memory v1 → v2 …". Its detail says risk tolerance is still "moderate" and was not inferred from the ended obligation. Open a memory chip: the drawer shows v1 superseded, v2 active, and downstream usage.

**2:35 · Governance (25s).** Switch persona to **Jordan Lee (Associate)** and run again: the restricted estate memory is excluded ("Excluded 1 × restricted"), its task is hidden, and Approve is disabled. Open **Compare** to show the three columns: without memory, with approved memory, after correction. Point out the label: a demonstration of memory influence, not proof of model causality. Optional: pick **Elena Ruiz (Harbor Ridge)**, whose similar "Sara Chen" never appears in Northlight's data.

**Extras if asked:** re-ingest the March note (the forgotten memory is not recreated); **Note with embedded instructions** (flagged, no effect on access); Daniel Okafor's spouse email (conflict → clarification task, the confirmed retirement age stays 62); Forget a memory (see what is removed and what is retained).
